02 / Safety

What qualifying does, exactly.

Worth spelling out, because "connect your wallet" is also the first sentence of most crypto theft.

01

You swap through Jupiter

The swap opens inside this page with LANDING fixed as the output. It is a real transaction from your wallet, so check the quote, the fees and any token warnings before you approve it. You can lose what you spend.

02

The registry checks it

Once the swap is finalized on Solana, the registry confirms it and records your LANDING balance at that moment. That number is a snapshot, not a live feed.

03

You get one permanent ID

One ID per wallet, for good. Come back on any device and restore the same card with the wallet address. The record is public, so anyone with the address can look it up.

04

Nothing else happens

No email, no password, no seed phrase, ever. If any page, bot or person claiming to be LANDING asks for a recovery phrase, it is a theft attempt. There is no exception to this and no support case that needs it.

03 / Badge

What it is worth.

!

Nothing, financially. A Certified Lander card is not an NFT, it is not tradeable, it does not entitle you to an airdrop, and it will never be a claim on anything.

It is a badge. Anyone offering to buy yours is running a different kind of operation.
