PRIVATE REVIEW / SOLANA MAINNETGRAVITY: ACTIVE
PREPARED FOR FINAL OWNER REVIEW

Last updated: 17 October 2026. Prepared for final owner review before production. Technical audit findings and verification limits are recorded in the private review notes.

1. What this site uses

The inspected LANDING application does not set first-party cookies and contains no analytics, advertising pixels or behavioural-profiling code. It does not use its own sessionStorage, IndexedDB or service worker. This is a statement about the inspected application, not a guarantee about every browser extension or external provider.

No LANDING consent banner is required at present for the technologies identified in the audit: functional storage and the Cloudflare technical/security cookie. No analytics, advertising tracking, profiling or equivalent non-essential tracking was identified as loading automatically in the inspected code. Provider-controlled browser behaviour can vary; a wallet-service activation is not blanket consent to unrelated tracking.

2. LANDING localStorage

  • landing:pending-signature — a transaction signature used to resume Certified Lander verification after interruption or reload. Written when verification starts; removed after a confirmed claim or an invalid result. Some interrupted or unresolved checks leave it available for recovery.
  • landing:lander-wallet — the public wallet address returned by the registry for a confirmed/restored card. Used to look up that same card on a later visit. It remains until cleared or replaced; the application sets no time-based expiry.

These are functional recovery records, not advertising identifiers. On a later visit to Certified Lander, a saved signature can restart verification and a saved wallet can trigger a registry lookup. Neither key contains a private key or seed phrase. Storage belongs to the current browser origin, so the private review site and final production domain do not share it.

3. Jupiter and wallet-provider storage

The Certified Lander page downloads Jupiter’s loader from plugin.jup.ag when opened. It does not preload the swap application. The current swap interface initializes only when you choose the buy/swap action; it then loads Jupiter’s application, styles, fonts and service requests.

The identified Jupiter-related storage is associated with wallet/swap functionality activated by the user. The inspected Jupiter wallet-adapter code includes functional localStorage paths named walletName, unified-wallet-previously-connected and SolanaMobileWalletAdapterDefaultAuthorizationCache. These can remember a selected wallet, previously connected wallet types or a mobile-wallet authorization, depending on the wallet and platform used. Their presence in code is not proof that all are written in every session.

Jupiter also bundles generic cookie and session-storage helpers. No specific cookie name or executed session-storage write was established from those helpers alone. Their exact runtime use and retention, and storage created by individual wallets, have not been verified in a live browser. See Jupiter’s privacy policy and your wallet’s policy. LANDING does not control those implementations.

4. External scripts and requests

  • Legal pages: use the existing same-origin site script and self-hosted fonts. They embed no third-party script.
  • Wall: loads Solana Web3 1.98.4 from jsDelivr and Wallet Standard App 1.1.1 from esm.sh. Wallet connection and signing occur through the wallet software you choose.
  • Certified Lander: loads the Jupiter loader and html2canvas 1.4.1 from jsDelivr when the page opens. html2canvas produces the card image in the browser. The heavier Jupiter interface loads after activation.
  • Infrastructure: Wall, Lander and Transparency contact the existing project API. The Lander video uses preload="none" and is requested from the official project site when played. External market, exchange, explorer and social links lead to independent services.

CDNs receive ordinary network request information when a library is requested. Fonts used by LANDING itself are self-hosted; the activated Jupiter component includes Google-hosted font styles. Third-party resources and wallet software may change independently of this site.

5. Hosting and third-party cookies

The inspected LANDING Worker and registry source contain no Set-Cookie instruction. Direct library-download checks did not return Set-Cookie headers. These checks do not establish that security infrastructure, private-review authentication or every activated third-party service is cookie-free.

The private review hosting response sets __cf_bm, a Cloudflare security cookie used for bot protection. Cloudflare documents expiry after 30 minutes of continuous inactivity. It is added by the hosting/security layer, not by LANDING application code. See Cloudflare’s cookie documentation. The final production host may have different settings.

The private build also requires ChatGPT Sites access. Other authentication or infrastructure storage is provider-managed and distinct from the two LANDING recovery keys. A full browser inventory, including after login and wallet activation, remains unverified. No additional cookie names or lifetimes are assumed.

6. Clearing storage

Use your browser’s site-data or privacy settings to clear cookies and local storage for the relevant origin. You can also remove the two named LANDING keys using browser developer tools. This resets locally remembered card recovery; an existing registry record can still be retrieved using its wallet address.

Clearing browser data does not delete the Lander registry, erase blockchain transactions, revoke permissions in a wallet application or disconnect an exchange account. Manage those permissions in the relevant wallet or service.

7. Changes and contact

Before deploying any new non-essential analytics, advertising, profiling or equivalent tracking technology, LANDING must update this policy and introduce valid purpose-specific consent controls that prevent that technology from running before consent. The same applies if previously unidentified non-essential tracking is discovered. Simply continuing to browse or choosing a swap is not general tracking consent.

Contact contact@landingcoin.fun. See the Privacy Policy for data handling and rights, and the Terms of Service for use of the site.
